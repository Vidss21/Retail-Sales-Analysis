📊 Retail Sales Analysis (Jupyter Notebook Project)
📌 Project Overview

This project focuses on analyzing retail sales data containing approximately 9,994 transactions. The goal is to explore sales patterns, identify key profit drivers, and extract meaningful business insights using data analysis techniques.

🎯 Objectives
Understand overall sales performance
Identify top-performing products and categories
Analyze profit and revenue trends
Discover customer purchasing patterns
Provide data-driven business insights
🛠️ Tools & Technologies Used
Python 🐍
Jupyter Notebook 📓

Seaborn
